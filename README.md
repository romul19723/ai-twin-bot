# 🤖 AI-Двойник RoboForex — Бот для привлечения партнёров

Telegram-бот на основе AI, который прогревает потенциальных партнёров RoboForex, отвечает на вопросы о трейдинге и пассивном доходе, анализирует графики и уведомляет владельца о горячих лидах.

## 🚀 Быстрый старт за 15 минут

### Шаг 1 — Создайте Telegram бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумайте имя и username боту
3. Скопируйте **BOT_TOKEN** — он выглядит так: `123456789:AAF...`

### Шаг 2 — Получите ключ Groq (бесплатно)

1. Зайдите на [console.groq.com](https://console.groq.com)
2. Sign Up → подтвердите email
3. **API Keys** → **Create API Key**
4. Скопируйте ключ — начинается с `gsk_...`

### Шаг 3 — Получите ключ OpenRouter (бесплатно, для анализа графиков)

1. Зайдите на [openrouter.ai](https://openrouter.ai)
2. Sign Up → подтвердите email
3. **Keys** → **Create Key**
4. Скопируйте ключ — начинается с `sk-or-...`

### Шаг 4 — Узнайте свой Telegram ID

1. Напишите [@userinfobot](https://t.me/userinfobot)
2. Он пришлёт ваш **ID** — это число вида `951626517`

### Шаг 5 — Задеплойте на Railway

1. Зарегистрируйтесь на [railway.app](https://railway.app)
2. **New Project** → **Deploy from GitHub repo**
3. Вставьте ссылку: `https://github.com/romul19723/ai-twin-bot`
4. Railway создаст проект — подождите сборку

### Шаг 6 — Добавьте переменные окружения

Railway → ваш сервис → **Variables** → добавьте каждую:

| Переменная | Значение | Описание |
|---|---|---|
| `BOT_TOKEN` | `123456:AAF...` | Токен от BotFather |
| `GROQ_API_KEY` | `gsk_...` | Ключ от Groq |
| `OPENROUTER_API_KEY` | `sk-or-...` | Ключ от OpenRouter |
| `OWNER_ID` | `951626517` | Ваш Telegram ID |
| `LANDING_URL` | `https://ваш-сайт.com` | Ваш лендинг |
| `REF_URL` | `https://rbfxdirect.com/...` | Ваша реф. ссылка RoboForex |
| `TG_BOT_URL` | `https://t.me/ВашБот` | Ссылка на вашего бота |

### Шаг 7 — Запустите

1. Railway → ваш сервис → **Settings** → **Deploy** → убедитесь что команда: `python roboforex_ai_twin_bot.py`
2. Зайдите в Telegram → найдите вашего бота → напишите `/start`
3. 🎉 Готово!

## 📋 Что умеет бот

- 💬 **Общается** как живой эксперт по трейдингу и инвестициям
- 📊 **Анализирует графики** — просто пришлите скриншот
- 🔥 **Уведомляет** вас когда появляется горячий лид
- 📈 **Прогревает** потенциальных партнёров RoboForex
- 🤖 **Помнит** историю диалога с каждым пользователем

## ⚙️ Команды для владельца

| Команда | Действие |
|---|---|
| `/stats` | Статистика — сколько пользователей и лидов |
| `/reset` | Сбросить историю диалога |

## 💡 Как получить реферальную ссылку RoboForex

1. Зарегистрируйтесь на [roboforex.com](https://roboforex.com)
2. Войдите в личный кабинет → **Партнёрская программа**
3. Скопируйте вашу реферальную ссылку

## ❓ Частые вопросы

**Сколько стоит?**
Railway — от $5/мес. Groq и OpenRouter — бесплатно. Итого ~$5/мес.

**Бот раскроет что он AI?**
Нет — это запрещено в его настройках.

**Можно изменить личность бота?**
Да — отредактируйте `SYSTEM_PROMPT` в файле `roboforex_ai_twin_bot.py`.

**Как проверить что всё работает?**
Напишите боту `/start` — он должен ответить приветствием. Пришлите график — он должен его проанализировать.
